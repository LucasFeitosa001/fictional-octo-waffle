# 03 — Profissionais

## User Stories
- Como admin, quero cadastrar profissionais, definir os serviços que executam, horários e comissão.
- Como admin, quero convidar profissionais por email/WhatsApp.

## Critérios de Aceite
- O SISTEMA DEVE permitir CRUD de profissional: foto, nome, apelido, celular, profissão, aniversário, ativo/inativo.
- O SISTEMA DEVE vincular serviços que o profissional executa.
- O SISTEMA DEVE registrar horários de atendimento (por dia da semana).
- O SISTEMA DEVE marcar se o profissional aparece no agendamento online.
- O SISTEMA DEVE permitir enviar convite e acompanhar status (pendente/aceito/expirado).
- QUANDO o convite é aceito, O SISTEMA DEVE criar usuário e vincular agenda.
- O SISTEMA DEVE armazenar regras de comissão por profissional (escopo serviço/produto/categoria/geral; percentual ou fixo).

- Cálculo/fechamento de comissão (Fase 2).
