# 02 — Clientes

## User Stories
- Como admin, quero cadastrar e gerenciar clientes.
- Como admin, quero ver o painel do cliente: débitos, créditos, histórico de agendamentos e comandas.

## Critérios de Aceite
- O SISTEMA DEVE permitir CRUD de cliente com campos: nome, apelido, celular, telefone, email, aniversário, CPF, CNPJ.
- O SISTEMA DEVE permitir busca por nome/telefone/email e ordenação por nome.
- O SISTEMA DEVE manter endereço(s) do cliente.
- O SISTEMA DEVE exibir saldo de créditos e cashback do cliente.
- QUANDO o cliente é desativado, O SISTEMA DEVE ocultá-lo das listas ativas sem apagar histórico.
- O painel do cliente DEVE mostrar histórico de agendamentos, comandas e assinatura.

## Abas (mobile)
Cadastro · Painel · Débitos · Créditos · Endereço · Usuário · Assinatura.

## Fora de escopo (fase 1)
- Anamneses (fase 4), usuário de acesso do cliente avançado.
