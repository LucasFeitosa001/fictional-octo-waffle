# 04 — Serviços

## User Stories
- Como admin, quero cadastrar serviços com preço, duração, categoria e configurações.

## Critérios de Aceite
- O SISTEMA DEVE permitir CRUD de serviço: nome, preço, duração (min), categoria, descrição, custo adicional, comissão, cashback, ordem de exibição.
- O SISTEMA DEVE ter flags: ativo, favorito, visível, permite agendamento online.
- O SISTEMA DEVE permitir busca e ordenação por nome.
- O SISTEMA DEVE permitir categorias de serviço (CRUD).
- QUANDO um serviço está invisível ou não-online, O SISTEMA NÃO DEVE exibi-lo no booking público.

## Fora de escopo (fase 1)
- Preços por profissional, tabelas promocionais (Fase 4).
